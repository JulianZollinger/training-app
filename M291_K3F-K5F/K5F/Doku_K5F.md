# K5F – UI/UX an einer konkreten Webseite erkennen und erklären

**Webseite:** ______________ (Webseite des Lehrbetriebs gemäss Arbeitsblatt; Alternative: intervals.icu)
**Partner/in:** ______________

Vorgehen: Seite durchklicken, zu jeder Wabe Bewertung (✔ / teils / ✘), Begründung mit konkretem Beispiel, Verbesserung.
Die Spalten "Begründung" bitte nach eigener Beobachtung ausfüllen – die Leitfragen helfen.

| Eigenschaft | Bedeutung | Leitfrage | Bewertung | Begründung (Beispiel von der Seite) | Verbesserungsvorschlag |
|---|---|---|---|---|---|
| Useful (nützlich) | Erfüllt echten Bedarf | Was kann ich hier tun, das mir hilft? | | | |
| Usable (benutzbar) | Einfach zu bedienen | Finde ich Ziel in wenigen Klicks? Klare Buttons? | | | |
| Desirable (begehrenswert) | Ansprechendes Design/Marke | Wirkt Design stimmig, modern, emotional? | | | |
| Findable (auffindbar) | Inhalte leicht zu finden | Navigation, Suche, Struktur klar? | | | |
| Accessible (zugänglich) | Für alle nutzbar | Kontrast, Schriftgrösse, Alt-Texte, Tastatur, Mobile? | | | |
| Credible (glaubwürdig) | Vertrauenswürdig | Impressum, Kontakt, aktuelle Inhalte, Fehlerfreiheit? | | | |
| Valuable (wertvoll) | Bringt Nutzen für Nutzer und Betrieb | Trägt die Seite zum Betriebsziel bei? | | | |
